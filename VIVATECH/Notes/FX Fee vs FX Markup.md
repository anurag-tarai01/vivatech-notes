These are different concepts.

### Markup

You alter the exchange rate.

Market:

```
1 USD = 600 XAF
```

Customer rate:

```
1 USD = 594 XAF
```

The difference is embedded in the rate.

---

### Fee

You can instead use:

```
1 USD = 600 XAF
```

and charge:

```
$1 FX fee
```

For example:

User converts:

```
100 USD
```

FX:

```
100 × 600

= 60,000 XAF
```

Then separately:

```
FX fee = 1 USD
```

Whether your MFS uses markup, fee, both, or neither is a **business requirement**, not an FX-provider requirement.
